Verificando autorização…

A importação está disponível apenas para o perfil de administrador autorizado.

1 · Selecionar o acervo criptografado

Escolha o arquivo original STAGIO_360_FI_M1_APROFUNDAMENTO_QUALITATIVO_RESTRITO_v1_6.html. A senha é utilizada apenas para descriptografar o arquivo no seu navegador, e não será enviada ao servidor.

A versão pública do GitHub continuará sem respostas individuais. Após sua confirmação, os dados serão enviados via HTTPS somente ao banco protegido do Supabase.

2 · Conferir quantidades

Importação auditável: nenhuma linha é enviada antes de clicar em confirmar.

Os textos dos alunos e das famílias podem mencionar pessoas identificáveis. Importe apenas para o projeto STAGIO 360 autorizado e não compartilhe cópias desprotegidas.
